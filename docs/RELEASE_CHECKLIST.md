- [ ] Confirm Q25 catalogue redistribution terms.
- [ ] Decide code licence.
- [ ] Check BibTeX metadata/titles.
- [ ] Add repository URL.
- [ ] Add `CITATION.cff`.
- [ ] Add input-data download/reconstruction instructions and checksums.
- [ ] Run a clean smoke test from a fresh directory.
- [ ] Create GitHub release `v1.0.0-paper-I`.
- [ ] Archive the release and full result tables on Zenodo.
- [ ] Add Zenodo DOI and GitHub URL to the paper Data Availability statement.
