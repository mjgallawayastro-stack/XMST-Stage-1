# Input data

The production runs used three input files:

- `quintana_2025_ob_stars_full.csv`
- `q25_group_membership.csv`

They are present in the original Paper I working archive but are not copied into this public-repository candidate pending a check of redistribution/licensing terms for the Q25 catalogue and derived membership table.
